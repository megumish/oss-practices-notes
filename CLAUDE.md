# Claude Instructions

This repository contains personal notes from exploring OSS repositories.

## Scope

- Keep observations grounded in specific repositories.
- Separate facts, interpretations, takeaways, and open questions.
- Do not turn a single case study into a general rule too quickly.
- Prefer adding repository-specific notes under `case-studies/`.
- Move ideas into `notes/` only when they are useful beyond one repository.

## Editing

- Follow the existing Markdown structure and concise tone.
- Use `templates/repository-study.md` for new repository studies.
- Preserve context when summarizing a practice: where it worked, why it worked,
  and where it may not transfer.
- Mark uncertain claims as hypotheses or questions.
